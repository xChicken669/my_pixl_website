# My PIXL Website

A personal website made for [Hack Club PIXL](https://pixl.hackclub.com).

## Description

This is a custom website about me and some of the things I enjoy. I built it using HTML and CSS, with a chaotic and colorful design.

The website includes moving goose images, an introduction about me and a GOOSE GALLERYYY

### Dependencies

You need:

- A modern web browser, such as Chrome, Firefox, or Edge.
- An internet connection to load the externally hosted goose images.
- Git, if you want to clone the repository from the command line.

No additional libraries or frameworks are required to run the website.
